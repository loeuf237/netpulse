# NetPulse 1.1.0 — Protected connections and local observability

## Added

- Connection protection enabled by default, deferred automatic assignments and
  explicit confirmations before desktop network changes.
- Read-only server TCP, tunnel, DNS and HTTPS diagnostics.
- Observed application rule states: applied, pending and failed.
- Local SQLite history for today, seven days and thirty days, with CSV export.
- Configurable server, data quota and sustained application-speed alerts.
- Local connection profiles with explicit activation and private storage.
- Regression tests, isolated GTK checks and wheel-content validation on GitHub.

## Fixed

- Socket counters, PID reuse, monotonic timing and session restoration.
- Atomic configuration writes, literal application matching and asynchronous
  controller error reporting.
- Direct-route copying, masked firewall marks and protected panel/tray shortcuts.
- Diagnostic URL validation and malformed settings handling.

## Upgrade notes

The interface in this version uses French. History starts when recording is enabled;
global physical TCP+UDP totals and sampled per-application TCP counts are distinct.
Profile activation can reroute traffic and remains a confirmed user action.
The desktop requires modern GTK4/Libadwaita libraries; old Ubuntu desktops are not
supported by their stock packages.
