# NetPulse 1.2.0 — English interface and Ubuntu CI/CD

NetPulse now provides an English interface throughout the desktop application,
GNOME indicator, tray menu, diagnostics, alerts, CLI and installer messages.

## Changes

- English labels, confirmations, profile validation messages and CSV column names.
- IEC byte units (`B`, `KiB`, `MiB`, `GiB`) for base-1024 traffic measurements;
  network bit units remain `bps`, `Kbps`, `Mbps` and `Gbps`.
- Ubuntu 18.04, 22.04 and 26.04 userspace test matrix with explicit coverage tiers.
- Full headless GTK tests on Ubuntu 26.04; controller and history tests on 18.04;
  monitor, controller, history and installer tests on 22.04.
- Version consistency checks, wheel verification, installable Linux x86_64 bundle,
  source distribution and SHA-256 checksums.
- Tag-triggered GitHub releases published only after every validation job succeeds.
- English README, compatibility table and release history.

## Compatibility

The desktop interface requires Python 3.10+, GTK 4.8+, Libadwaita 1.4+ and
librsvg 2.46+. Ubuntu 26.04 supplies the required desktop libraries.
Ubuntu 18.04 and 22.04 test selected components; their stock desktop libraries
cannot run the current interface. The 18.04 job uses a managed Python 3.10.
Containers share the runner kernel, so these jobs do not certify old kernels,
real firewall rules, live GNOME sessions or end-to-end proxy routing.

## Installation and upgrade

Download `netpulse-1.2.0-linux-x86_64.tar.gz` and `SHA256SUMS` from this release.
Verify its checksum, extract the archive and run `./install.sh` as your desktop user
for a new installation. The wheel is for Python packaging; it does not install
sudoers, systemd units, icons, the GNOME extension or the bundled tun2socks binary.

For an existing active tunnel, use `python3 live-upgrade.py` from the extracted
bundle. It backs up the existing installation, preserves the active tunnel and
routes, resumes counters and leaves existing windows open. If it reports that the
root controller must be updated, follow the active-connection instructions in the
README before retrying. Do not use uninstall/reinstall as a live upgrade.

The GNOME extension update takes effect in the next GNOME session. Saved profile
names and previously stored event messages retain the text originally entered or
recorded. New events use English. No profile is activated automatically.
